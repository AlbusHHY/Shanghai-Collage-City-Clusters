# Shanghai Collage City Clusters

[Open the interactive platform](https://albushhy.github.io/Shanghai-Collage-City-Clusters/)

## Participatory cluster validation

For participatory validation of the identified urban-form clusters, we developed an interactive platform that combines multi-scale visualization with public voting.

There is no fixed voting sequence. Participants can select any spatial scale, explore the map, and click a cluster they recognize or know well. Each vote records two judgments:

1. **Area familiarity** — whether the participant is *very familiar*, *moderately familiar*, or *unfamiliar* with the selected area.
2. **Boundary match** — whether the detected cluster extent provides a *strong match*, *moderate match*, or *no match* with the participant's understanding of the area.

The platform displays the accumulated results as summary charts for each cluster. Votes are stored only as anonymous aggregate counts; visitor IDs, IP addresses, and individual ballots are not retained.
